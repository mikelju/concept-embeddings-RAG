## T3: `CachedQueryBackend` [Story: HU-1, HU-4] [depends on T2]

  `tests/embeddings/test_question_cache.py`

  **Raises on a miss** (decision D1): a fallback to the real model would make the sweep slow without

  cache metadata so provenance in the result config is unchanged.
- **Verification**:
  - [x] `DenseRetriever` runs against it with **no modification to `dense.py`**
  - [x] An unknown query string raises; nothing falls back to encoding
  - [x] Two identical questions in the split resolve to the same vector, no duplicate storage

## T4: Query -> concept operators [Story: HU-1] [depends on T1]

- **Files**: `src/concept_embeddings_rag/retrieval/__init__.py`,
  `src/concept_embeddings_rag/retrieval/conceptual.py`,
  `tests/retrieval/test_query_operators.py`
- **Action**: `query_concepts(vector, dictionary, operator, top_m=None, alpha=None) -> np.ndarray`
  covering the three arms of D4: projection clipped at zero with and without top-m truncation, and
  sparse coding through `dictionary.encode` at the corpus coding alpha. Every parameter returned
  alongside the vector for the record, none of them defaulted inside the function body.
- **Verification**:
  - [x] Same question + same dictionary -> bit-identical concept vector on repeated calls
  - [x] Projection output is non-negative and has exactly `top_m` non-zeros when truncated
  - [x] Sparse coding output is non-negative and sparse
  - [x] The function's only inputs are a vector and a dictionary: no question text, no split, no gold

  - [x] Both `raw` and `row_normalized` matrices load and produce different rankings

## T7: Rarity damping [Story: HU-6] [depends on T5]

- **Files**: `src/concept_embeddings_rag/retrieval/conceptual.py`, `tests/retrieval/test_damping.py`
- **Action**: `rarity_weights(support, n_units) -> np.ndarray` implementing decision D7's
  `log(1 + N / (1 + df))`, applied multiplicatively to the query vector. Support read from the Phase 2
  diagnostics artifact, never recomputed. `damping="none"` is the identity and must be provably so.
- **Verification**:

  - [x] A concept active on every unit is demoted relative to a concept active on thirty
  - [x] The dictionary and the matrix are byte-identical before and after a damped run
  - [x] The damping mode travels in the retriever's recorded config
