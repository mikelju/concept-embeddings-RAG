## T2: The diffusion operator [Story: HU-1] [depends on T1]

- **Files**: `src/concept_embeddings_rag/retrieval/diffusion.py`,
  `tests/retrieval/test_diffusion_operator.py`
- **Action**: `DiffusionOperator` built once from the inherited `X` and the inherited concept weights:
  degrees `d_u`, `d_c`, the three normalization arms of D3, and `propagate(s) -> u` as the two sparse
  products `X (w ⊙ (Xᵀ s))`, L1-normalized on the way out. A zero degree raises.
- **Verification**:
  - [x] One step matches a **hand-computed reference** on a small dense matrix, in all three arms
  - [x] The unit x unit product is never formed: the only matrix operands are `X` and `X.T`
  - [x] `stochastic` preserves mass before renormalization, to float tolerance
  - [x] A matrix with a zero row or a zero column raises rather than dividing

## T3: Seed mass [Story: HU-2] [depends on T1] [P]

  `tests/retrieval/test_seed_mass.py`
- **Action**: `seed_mass(hits, unit_index) -> (np.ndarray, int)` of decision D1: clip at zero,
  L1-normalize, return the vector and the count of clipped hits. No score, no rank, no constant.
- **Verification**:

  - [x] All-zero or empty seed output is refused with a message naming the seed, not silently uniform
  - [x] A negative score is clipped **and counted**, and the count reaches the caller

## T4: `DiffusionRetriever` [Story: HU-1, HU-3] [depends on T2, T3]

- **Action**: the spec's data contract as a runtime object - `name`, `matrix`, `dictionary`,
  `seed_retriever`, `seed_arm`, `restart`, `normalization`, `stop_threshold`, `max_iterations`,
  `concept_weights`, `inherits` - plus `describe()` and `retrieve()`: `s_{t+1} = restart * s_0 +

- **Verification**:

  - [x] Returns at most `top_k` hits, best first, deterministic across runs including ties
  - [x] The matrix/dictionary agreement is checked in the constructor, as `ConceptualRetriever` does
  - [x] The restart is applied at **every** iteration, asserted on a traced two-round run
