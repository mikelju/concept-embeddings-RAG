# Phase 15 — RunPod operating recipe

> Operational runbook for the **pod half of plan step S3**: the BGE-small encoding (`embed`) and
> the GLiNER extraction (`extract`) over the MuSiQue corpus. Everything else in S3 runs on the
> laptop: `bm25` before the pod, `index` after it.
>
> **Stop point 1.** Nothing here is started before the author approves this recipe, the
> contracted hourly rate and the frozen commit. On the pod, **if the session reaches 2 USD, stop
> the pod and ask the author before anything else.**
>
> No metric of any MuSiQue question is computed on the pod. The pod encodes and extracts; it
> retrieves nothing.
>
> Files move through the pod's **Jupyter** file browser (upload and download). Every command
> below runs in the pod's terminal unless it says "laptop". Labels: **measured** (read off an
> artifact), **derived** (arithmetic on measured values), **projection** (not a measurement).

## 4. Pod setup (terminal)

Everything `uv` needs lives on the volume (its binary, its cache, the Python it installs and the
Hugging Face cache), so a pod stop loses nothing.

```bash
cat > /workspace/env.sh <<'ENV'
export UV_INSTALL_DIR=/workspace/.uv/bin
export UV_CACHE_DIR=/workspace/.uv/cache
export UV_PYTHON_INSTALL_DIR=/workspace/.uv/python
export HF_HOME=/workspace/.hf
export PATH=/workspace/.uv/bin:$PATH
ENV
source /workspace/env.sh

cd /workspace
git clone https://github.com/mikelju/concept-embeddings-RAG.git
cd concept-embeddings-RAG
git checkout 7aed3dbfc96a330999f7c2fb9e8b7159f2a5b043
git rev-parse HEAD && git status --short

curl -LsSf https://astral.sh/uv/install.sh | sh
uv sync --group phase7

```

## 7. Build: one process per step, one step at a time

**Step 1, `embed`** (about 1-2 min, projection):

```bash
nohup uv run --group phase7 cer p15-build --stage embed --hourly-rate-usd <RATE> > data/phase15/logs/embed.log 2>&1 &
tail -n 3 data/phase15/logs/embed.log     # repeat until "[OK] p15-build embed"
```

**Step 2, `extract`**, only after step 1 printed `[OK]` (about 7-15 min, projection):

```bash
nohup uv run --group phase7 cer p15-build --stage extract --hourly-rate-usd <RATE> > data/phase15/logs/extract.log 2>&1 &
tail -n 3 data/phase15/logs/extract.log   # repeat until "[OK] p15-build extract"
```

- `nohup` keeps each step alive if the browser closes.
- `embed` writes `data/phase15/cache/` (the passage vectors and `embedding.json`) and
  `data/phase15/cache/questions/` (the 2,417 validation and 200 live-path question vectors).
  It refuses to run twice. If it dies after writing the vector cache but before
  `embedding.json`: **STOP** and ask.
- `extract` writes `data/phase15/nodes/` (`extraction.json`, `records.jsonl.gz`, `shards/`).
  It is resumable at shard level (100,000 units per shard, so 2 shards): if it dies, rerun the
  same `nohup` line once. A second failure: **STOP** (two attempts without progress).
- Both steps refuse a corpus whose files do not match `corpus.json`; `extract` also refuses a
  corpus S2 stopped for GLiNER's window. Any refusal: **STOP**.

Quick look at what was recorded (no metric is involved):

```bash
python3 -c "import json; b = json.load(open('data/phase15/cache/embedding.json')); print(b['n_units'], b['n_questions'], b['wall_seconds'], b['paragraphs_per_second'], b['hardware']['gpu'])"
python3 -c "import json; b = json.load(open('data/phase15/nodes/extraction.json')); print(b['configuration_digest'], b['configuration_digest_matches'], b['attempted'], b['failures'], b['wall_seconds'], b['hardware']['gpu'], b['gliner_window']['units_over'])"
```

The first must show 101962 and 2617; the second `2f7864661b8ce7ff True 101962` and 56 units
over the window (the S2 count, carried).
