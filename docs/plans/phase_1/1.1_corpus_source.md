# Deviation 1.1: the official HotpotQA host is unreachable

> Phase: 1 | Detected during: T14 (real pipeline run) | Status: resolved

## Problem

`cer fetch` failed against the source declared in the spec and in `config.py`:

```
http://curtis.ml.cmu.edu/datasets/hotpot/hotpot_dev_distractor_v1.json
-> httpx.ConnectTimeout (WinError 10060)
```

This was the risk written down in the phase plan ("Known risk - the download URL"),
so it was handled as planned rather than improvised.

## Root cause

The host is the authors' own server at CMU and it does not answer. It is not a local
network problem: `huggingface.co`, `github.com` and the HuggingFace datasets API all
responded normally in the same check.

## Options considered

| Option | Verdict |
|---|---|
| Parquet files from the HuggingFace dataset repo | Rejected. 27 MB and readable only with `pyarrow`, which has no `win_arm64` wheel — the same wall that ruled out HuggingFace `datasets` during scaffolding |
| A third-party copy of the JSON on GitHub | Rejected. Unverifiable provenance for the artifact every number in the project rests on |
| **HuggingFace datasets-server rows API** | **Adopted.** Serves the canonical `hotpotqa/hotpot_qa` dataset (config `distractor`, split `validation`, 7,405 questions) as plain JSON, needing no new dependency |

## Adopted solution

`cer fetch` now pages through the HuggingFace rows API and assembles the full split
locally, normalizing each row back into the original HotpotQA shape (`_id`,
`context` as `[title, sentences]` pairs, `supporting_facts` as `[title, sent_id]`
pairs). The assembled file is written once and frozen with its SHA-256, exactly as
before.

## Impact

- **Spec**: unchanged. HU-1 says the corpus is downloaded from its official URL and
  frozen with its hash; the canonical distribution simply moved to the HuggingFace
  hub. Every acceptance criterion still holds.
- **Reproducibility**: slightly stronger, in fact. The frozen artifact is hashed on
  our side and the manifest records both the dataset id and the API used, so a rerun
  verifies against that hash rather than trusting a remote host.
- **New code**: `corpus/hf_source.py`, plus its tests. `config.py` keeps the dead
  official URL recorded for provenance.
- **Cost**: 75 paged requests, a few seconds. No new dependency.

## Note for the user

The phase plan committed to deciding the mirror with the user rather than swapping it
silently. This is that notice: the source in use is the canonical HuggingFace dataset,
not a third-party copy. If you would rather use a different source, it is one
constant in `config.py` and a rerun of `fetch`.
