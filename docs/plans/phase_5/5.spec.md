# Phase 5 Specification: Research Closure and Verdict

## Purpose

Close the first research line without starting a new experiment. The purpose of this phase is to turn the executed evidence into a bounded, reproducible scientific statement: what the current implementation tested, what the measured results rule out, what they do not rule out, and what the repository should consider the end of this line of investigation.

## Scope

This phase is documentary. It does not introduce a new retrieval method, benchmark, model, hyperparameter sweep, or evaluation metric.

The closure covers the operationalization actually evaluated:

> corpus-induced concepts obtained by sparse dictionary learning over pooled dense paragraph embeddings, used for conceptual retrieval, score fusion, and diffusion-based iterative expansion on HotpotQA distractor validation.

The closure must preserve the distinction between that operationalization and the broader hypothesis in `docs/refs/descripcion-proyecto.md`.

## Required outputs

1. A final results record with the principal test figures and the mechanical failure analysis.
2. An explicit scientific verdict with a scope boundary.
3. A record of unresolved construct-validity and benchmark-validity questions.
4. A repository-status note identifying any gap between the evidence being closed and the Git history that is currently available.
5. A README status that prevents the project from being presented as an unfinished implementation of the next experiment.

## Acceptance criteria

- The negative result is stated at the same prominence as the positive baseline result.
- The current implementation is not presented as a definitive refutation of the original hypothesis.
- The comparison against dense + BM25 is explicit.
- The main mechanical failure of iterative expansion is documented.
- Tested and untested levers are separated.
- The next step is a clearly bounded pilot, not an implied commitment to a full-scale reimplementation.
- No test-split result is recomputed or silently replaced during closure.
