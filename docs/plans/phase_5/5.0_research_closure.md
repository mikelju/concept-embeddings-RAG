# Phase 5 Plan: Research Closure

This phase closes the executed concept-space investigation before any new mechanism is implemented.

## 1. Freeze the interpretation

Treat the technical review dated 2026-09-15 as the source used to write the closure. Do not broaden its claims. The central result is scoped to the implemented representation and benchmark.

## 2. Record the result

Record the test comparison at 2,048 tokens:

| System | Full Support |
|---|---:|
| Concepts alone | 0.355 |
| BM25 | 0.759 |
| Dense | 0.825 |
| Dense + concepts (System B) | 0.825 |
| Diffusion expansion, dense seed (System C) | 0.821 |
| Dense + BM25 control | 0.864 |

The closure must also preserve the reported development diagnostics: System C did not promote a new paragraph, the second-hop concept diagnostic underperformed simpler continuation, and the hardest shared-baseline failures were bridge questions whose missing paragraph was often linked by a named entity already present in retrieved material.

## 3. Bound the negative verdict

The supported conclusion is:

> The tested pooled-embedding concept formulation does not provide measurable complementary retrieval value over the dense baseline, either through score fusion or diffusion-based expansion, on this HotpotQA setup; a dense + BM25 control is materially stronger.

The closure must explicitly reject the stronger claim that the original idea of text-derived, interpretable concepts is disproven.

## 4. Register the design limitations

The closure must retain the critical limitations identified in the review:

- the concept representation is a sparse recoding of the dense paragraph embedding and therefore is structurally unlikely to add information outside that embedding;
- HotpotQA's heterogeneous entity-centric paragraphs and bridge-by-name questions are not the same task as the original homogeneous-corpus / thematic-satellite hypothesis;
- the Phase 4 seed/restart/operator combination made candidate-set expansion ineffective for the tested restart range;
- the strongest baseline was not tested with a stronger embedding model or reranker;
- response-level and Type-C satellite evaluation were not performed.

## 5. Close the line of work

Do not tune the current Phase 4 implementation further as the default next step. Preserve it as a negative experimental result. The recommended continuation is a small pilot with text-derived entities/concepts on the failure cases before any full-scale reimplementation.

## 6. Repository integrity

The review supplied for this closure references later Phase 4 result commits and artifacts that are not present in the GitHub branch used as the base of this closure. This discrepancy must be stated explicitly rather than silently repaired by changing the historical interpretation. The closure therefore documents the scientific conclusion and the synchronization gap separately.
